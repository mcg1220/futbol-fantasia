First time doing this? Read the setup steps
One-time setup (only ever needed once per computer): 
git clone https://github.com/mcg1220/futbol-fantasia.git
cd futbol-fantasia
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
pip install playwright
playwright install chromium
Every time you open a new terminal window/tab, before running the command below — this is the step people keep missing (running it from the wrong folder, like your home folder, gives a "no such file or directory" error): 
cd futbol-fantasia
source venv/bin/activate
cd scripts
Then run the generated command below. You can leave the same terminal tab open and just re-run it again later with new match IDs, as many times as you want — no need to repeat the steps above until you close that tab.
